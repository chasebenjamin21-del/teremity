# Teremity: notes for Claude

Teremity is an offline PWA (Preact + Vite + vite-plugin-pwa) that serves as an Elden Ring field guide for Chase and his wife Truc. Truc uses it on an iPad while Chase plays (Switch 2, Tarnished Edition). The character is named Teremity.

## How it's built
- `npm run build` writes the site to `docs/`; GitHub Pages serves `main` /docs at https://chasebenjamin21-del.github.io/teremity/ (base path `/teremity/`).
- `src/data/world.json` is generated by `tools/compile_world.py` (graces, bosses, places, loot, Chase's markers, region shapes). Coordinates come from GraceMap (GPL-3.0); x = lng, y = -lat. Farum Azula is shifted 38 units west for display.
- Hand-written content lives in `src/content/` (regions, glossary, boss tips, plan/build/secrets). Write in plain, literal English for Truc: full sentences, no shorthand or arrows, no irony.
- `src/components/MapView.jsx` pans and zooms by rewriting the SVG viewBox and a `--s` CSS variable; pins use CSS transforms so they keep a constant screen size.
- State lives in localStorage (`teremity.v1`) via `src/lib/store.js`.

## Rules
- Never copy the game's map art or wiki text. Facts are fine; the drawing and writing must be original.
- Story spoilers go inside `<Spoiler>`.
- Keep both themes (night and day) working, and test at iPad landscape, iPad portrait and phone widths.
- Commit messages end with the attribution lines the session asks for.
